Access notes

This page does not ask for, transmit, or store a password. It uses only anonymous Google endpoints. If the sheet is private, Google normally returns a sign-in/access page instead of sheet data. Make it readable to anyone with the link or publish it only if that access level is acceptable for the data.

Some browsers block cross-origin reads or local-file requests. If the page reports a browser access block, host this HTML on HTTPS (for example, GitHub Pages) and try again. A successful read may use an anonymous Google endpoint; this test does not change sharing settings.
